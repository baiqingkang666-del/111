## 1. 创作核心

- **主题**：越走越高，成就越来越多，却忘了为何出发；最后想起初心，把它传下去。每一座山顶，都是下一座山的山脚。
- **视角**：中国石油大学（华东）唐岛湾校区一名大学生的四年。
- **虚实比例**：登山（虚）约 55%，校园与书桌（实）约 30%，抽象段（云海、宇宙、胶片回放）约 15%。**实景镜头少而精，只用远景或微缩景，不做建筑特写。**
- **节奏**：多数镜头是 1–2 句歌词的长镜头（约 4–8 秒），只在“四个也许因为”处按每句 2 秒快切。

## 2. 美术规格

### 2.1 渲染风格
- 全片统一的光线步进 3D 世界：一座巨大的山，山脚临海（唐岛湾），校园就在山脚。地形算法沿用 `sFly` 的 ridged fbm + 软阴影 + 指数高度雾 + 体积云，画质只能比它更好。
- 微缩模型质感：暖色主光、柔和阴影、AO、浅景深（远近虚化）、轻微移轴感。
- 后期沿用 post.glsl（bloom、颗粒、2.35:1 遮幅），按段落调色。

### 2.2 时间与天气弧线（三遍副歌同机位，靠光线区分）

| 段落 | 时间 | 光线与天气 | 色调 |
|---|---|---|---|
| 序 + 副歌一 | 0–33.9 | 清晨日出、薄雾 | 粉金、淡青 |
| 主歌 | 33.9–80.7 | 正午 → 云雾 → 风雪 | 由亮转灰白 |
| 副歌二 | 80.7–112.1 | 雨夜、闪电 | 冷蓝、低饱和 |
| Rap | 112.8–158.5 | 深夜海边 → 星空 → 黎明 → 山顶晨光 | 深蓝 → 金 |
| 副歌三 + 尾 | 160.2–196.6 | 金色夕阳 | 橙金、暖 |

### 2.3 角色：卡通小人“小石”
- 参考 Claude Code 吉祥物那种极简卡通感：圆润的方块身体（头身一体），陶土橙色哑光材质，两只黑豆眼，短小的四肢，背一个小书包。不画嘴；情绪靠姿态（耷拉、蹦跳、仰头）和眼睛形状（圆 / 眯 / 弯）表达。
- SDF 搭建：圆角盒身体 + 胶囊四肢；走路时身体左右摇摆、上下弹跳，步频卡 `beat()`。
- 其他角色同一风格，换颜色、换大小：父母是大一号的暖灰色；同学是各种柔和的颜色；结尾的新生是浅蓝色。
- 小人在画面里通常较小（占画高 5–20%），避免大特写暴露建模粗糙。

### 2.4 贯穿物：纸飞机
- 白色纸张，带折痕的低面数 SDF（一个三角翼 + 中脊），边缘有一点透光。纸面上能看到手写字。
- 纸条文字（字幕层用楷体，渲染成纸面贴图或叠字）：
  - 正面：**我为什么出发？**
  - 背面（D6 写下，E7 揭示）：**别忘了出发时的样子**（占位，用户可能会替换）
- 状态变化：崭新 → 被风卷走 → 湿透漂在水里 → 展平重折 → 交给新生。

### 2.5 第一视角（POV）
用摄像机模拟人物状态，全部在相机或后期里实现：
- 镜头高度在小石眼睛的位置；画面下缘偶尔露出两只橙色小手（例如握着纸飞机）。
- 走路时头部上下颠、左右摆，卡节拍；疲惫时幅度变大、节奏变乱。
- 呼吸：画面缓慢缩放 ±1%；紧张时的心跳脉冲跟 `KICK` 走。
- 疲惫或迷茫时：暗角加重、降饱和、边缘模糊。
- 雨雪天：镜头上有水滴或雪花附着，带折射。
- 低头看脚、抬头看山顶这两个动作要做得明确。

### 2.6 地标（没有参考照片，一律简化，不要编造建筑细节）
- **“创造太阳”女神像**：面海而坐，双手托举一颗发光的金色球体。用风格化的石质 SDF 人形剪影表现即可。全片起点和终点都在这里。“巨人肩膀”就是她的肩膀。
- **唐岛湾**：海面，带反射、波光和海岸草地。
- **校园**：山脚下一片微缩楼群，窗户会发光；只出现在远景和航拍里。
- **书桌**：自习室或宿舍的微缩桌面，有书堆、台灯、证书、日历，可以做浅景深近景。这是“实”里最容易做得精美的部分。

## 3. 分镜（时间来自 lyrics_timed.tsv）

镜头类型：【虚】登山或抽象，【实】校园、书桌、海边，【POV】第一视角，【T】纸飞机驱动的转场。

### 序（0.0–2.7）清晨
- **P00 【实】** 从黑场浮出唐岛湾日出。镜头贴着海面低掠，推向岸边女神像的逆光剪影，她托着的金球与初升的太阳重合。标题“山脚”出现（沿用旧版标题样式）。

### 副歌一·出发（2.7–33.9）清晨薄雾
- **A1 【实→虚】2.7–10.5**（踩着巨人肩膀把你送到山脚 / 走了半天都还没走到半腰）
  - 女神像脚下的海边草地，两个大一号的小人（父母）陪着小石。
  - 镜头从女神像肩后升起、越过她的肩头，露出校园身后那座巨大的山。
  - 镜头继续升，校园只是山脚下的一小片。小石沿山路出发，小得像一粒米，山腰远在云上。
- **A2 【虚】10.5–14.4**（如果爬山就是一直在走弯道）：俯拍 Z 字山路，小石沿弯道走，背包上插着纸飞机。
- **A3 【虚·POV】14.4–18.7**（有云雾环绕 / 坏天气不停干扰）：第一视角走在山道上，雾从前方涌来，风声中镜头摇晃；两只小手在画面下缘护着纸飞机。
- **A4 【虚】18.7–22.1**（但就算登上山顶其实也不算高）：小石爬上一座小峰，举手蹦跳。镜头一路拉远，小峰只是巨山肩部的一块石头。
- **A5 【实】22.1–26.0**（过了旧的关会有新的烦恼）：书桌微缩，录取通知书被课表、四六级报名表、绩点单一张张盖住。
- **A6 【虚·POV】26.4–32.7**（当你跨过下个台阶下个转角 / 会发现一山比一山高）：第一视角爬石阶、转过拐角后抬头，群山一层比一层高，一路叠进云里。
- **A7 【虚】32.7–33.9**（越过后才能看到）：小石站在崖边，把纸飞机用力掷出。【T：镜头跟着飞机冲出去】

### 主歌·越卷越高，忘了为何出发（33.9–80.7）正午 → 云雾 → 风雪
- **B1 【虚】33.9–38.4**（想要登上高山欲穷千里目 / 回头看看赶了不止千里路）
  - 跟拍纸飞机，越过群山和唐岛湾，视野无比开阔。
  - 飞机回转，镜头回望：一条发光的小路从海边女神像一路蜿蜒上山，那是走过的千里路。
- **B2 【虚·POV】38.4–42.4**（怎么越走越高越云里雾里 / 不如问问自己为何全力以赴）
  - 飞机钻进云层。【T：全白】
  - 白雾中切到第一视角，两只小手接住飞回来的纸飞机。纸上的“我为什么出发？”被雾气洇得模糊。
- **B3 【实+虚】42.4–50.1**（四个“也许因为……”，每句约 2 秒，同一机位逐级上升，卡强拍）
  - 书桌上，书堆成一座小山，小石在书山上攀爬。
  1. 42.4 也许因为甜头刚入口：一张金色奖状落在书山脚下，闪光。
  2. 44.3 也许因为野心像是高度酒：台灯的光像琥珀色酒液漫过书山。
  3. 46.2 也许因为人总要往高处走：书山长高一截，小石继续往上爬。
  4. 48.2 也许最想要的东西不是到处有：书山顶上只有一个位置被一束聚光照亮。
- **B4 【虚】50.1–57.4**（什么才是成功还不懂 / 不过听起来就让人觉得迷恋 / 人是一个永远不会觉得满足的物种 / 就像那句「只有天空才是极限」）
  - 小石站在书山顶，头顶像天空一样铺开一块巨大的发光屏幕，一张张“offer / 保研 / 获奖”卡片像星星一样滚过。
  - 小石仰头。镜头冲上屏幕，穿过去，变成真实的天空。【T】
- **B5 【虚】57.9–61.6**（上山的路可能永远没有尽头 / 来探路的永远不知疲倦）：3D 航拍，全片画质展示镜头之一。黄昏的山脊上，无数亮着头灯的小人排成长线，一路延伸进云端。
- **B6 【虚】61.6–65.5**（动力来自于山顶上的一切 / 和被踩在了脚底下那一片）
  - 仰拍山顶的金光。
  - 镜头下摇到小石脚下的雪地：一把小吉他、一个篮球、一部亮着“妈妈 来电”的小手机，被踩在脚印里。
- **B7 【虚·POV】65.5–69.0**（等到爬的越来越高 / 脚底下的步伐越来越飘）：第一视角低头看脚，每走一步，脚下的岩石就碎裂、悬空、漂走。呼吸越来越急，画面跟着脉动，晃动加剧。
- **B8 【虚】69.0–72.9**（以为只要站的高一点才能看得远 / 才能早有预料）：小石站在最高的一块浮石上，镜头绕它转一圈，四周全是白茫茫的云海，什么也看不见。
- **B9 【虚·POV】72.9–76.8**（于是都绷起勒紧裤腰 / 把山顶当成最终目标）：风雪中的第一视角，小手把背包带勒紧，雪花糊在镜头上。正前方的山顶只剩一颗孤星，镜头死死盯着它。
- **B10 【虚】76.8–80.7**（为了可以拿到完美人生入场券 / 同时拥有诗和面包）
  - 山顶上出现一道发光的门，金色入场券像雨一样落下，小石伸手去抓。
  - 背包上的纸飞机被风卷走，消失在风暴里。【T：风暴吞没画面，接副歌二】

### 副歌二·同样的词，更沉重（80.7–112.1）雨夜。与副歌一同机位，刻意镜像

- **C4 【虚】96.1–99.5**（同 A4 机位）：小石爬上同一座小峰，没有欢呼。闪电一亮，照出上方高得多的山。

- **C6 【虚·POV】103.5–110.1**（同 A6）：第一视角爬无尽的石阶，阶梯的灯一级级亮起，转角之后还是转角。

- **D1 【虚】112.8–115.9**（曾经仰望的尖 / 是你以为伸手就能摸到的天）：回忆镜头，褪色、带胶片颗粒。很小的小石站在山脚仰望山尖，伸出手。
- **D2 【虚·POV】115.9–119.5**（结果发现登顶不过只是跨过了边 / 重新来到下个山脚翻掉过去的篇）：第一视角跨过一道山脊线，另一侧又是一个山脚。【T：整个画面像书页一样翻过去】
- **D3 【虚】119.7–123.9**（不必留恋 曾经堆满筹码的桌上 / 谁都知道那种感觉有多棒）：小石把书包上的奖牌一个个摘下，它们被风吹散成金色碎纸，飞向夜空。
- **D4 【实】124.1–128.8**（但我需要继续前进继续盲人摸象 / 继续高低来回像是海上的波浪 / 继续用力碰撞）：夜里的唐岛湾，小石沿海岸奔跑，镜头随浪起伏，卡拍。
- **D5 【虚】128.8–133.5**（继续走在我的路上不管外面多么动荡 / 练出更大颗的心脏可以承受更多的重量）：小石把湿纸飞机展平，重新折好，然后逆风前行，风暴被甩在身后。它胸口亮起一点光，随鼓点跳动。
- **D6 【实】133.5–136.3**（我羡慕的故事由我自己来奉上 / 没空沾沾自喜）：特写，小手在纸条背面写下一行字（字先不露全，留到 E7）。
- **D7 【实】136.5–140.2**（当我站在巨人肩膀上能看到更加辽阔以后 / 甚至更加了解自己）：小石坐在女神像的肩头。这是“巨人肩膀”的正解，全片呼应点之一。夜空在头顶铺开。
- **D8 【虚】140.2–143.0**（谁还不是一粒微小尘埃活在这个茫茫宇宙）：一镜拉远，小石 → 女神像 → 唐岛湾 → 地球 → 星河。
- **D9 【虚】143.0–148.4**（比起轻松达阵得分 / 奋力冲向山顶上的过程我更钟爱 / 那种后来居上弯道超车）：从星河俯冲回地面，跟拍纸飞机高速穿过山谷的弯道。全片速度感最强、画质展示的重点镜头。

### 副歌三·毕业，新的山脚（160.2–191.3）金色夕阳。与 A、C 同机位
- **E1 【实→虚】160.2–167.3**（同 A1 / C1 机位）
  - 女神像下，夕阳。小石戴着学士帽，父母又站在身边，这次是小石踮脚搭着他们的肩。

## 4. 实现要点

1. **重写 scene.glsl**：一个统一的 3D 世界，由以下几部分组成：
   - 地形：巨山 + 海岸 + 校园平台，可沿用 `terH` / `rfbm` 的思路。
   - 海面。
   - SDF 物体：女神像、小人、纸飞机、书桌道具、浮石、门、学士帽。
   - 天空：太阳、星空、体积云。
   - 天气：雾、雨、雪、闪电。

   每个镜头的相机位置、目标点、FOV、时间段、天气、道具开关都由 render.py 通过 uniform 传入。书桌场景可以做成同一个世界里的独立“棚景”，与山的场景分开。
2. **镜头表**：把 render.py 里的 `SHOTS` 换成关键帧结构，比如 `(start, shot_id, transition, cam_from, cam_to, ease, …)`，每个镜头内部做插值运镜。转场类型：cut、溶解、白闪（云）、风暴、水面翻转、翻页、匹配剪辑。
3. **POV 效果**：头部晃动、呼吸放在相机里做；镜头上的雨滴雪花、疲惫暗角和降饱和、心跳脉冲放在 post.glsl 里做，用 uniform 控制强度。
4. **字幕**：`LYR` 改为读取 `lyrics_timed.tsv` 全部 78 句，样式沿用旧版。主歌和 Rap 的句子很密，字幕淡出时间缩短，避免两句重叠。
5. **验收流程**：
   - 先按段落出接触表，每个镜头取 2–3 个时间点，自查画面是否精美、是否与分镜一致。
   - 然后出 960×540 预览视频检查节奏。
   - 最后渲染 1080p 成片，输出 `D:\mv\山脚_MV_v2.mp4`。
6. **画质底线**：任何镜头都不能比旧版 `sFly` 那段难看。哪个实景镜头做不精美，就改成更远的景别或更多雾气，宁可简化，不要粗糙。
